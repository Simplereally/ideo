# ideo

## Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4 + Shadcn UI
- **Package Manager:** Bun
- **Storage:** Cloudflare R2 (via Presigned URLs)
- **Deployment:** Vercel / Cloudflare Pages

## Architecture Notes
- This is a lightweight frontend-heavy app.
- We avoid heavy backend processing.
- Images are uploaded **directly** from the client to Cloudflare R2 using presigned URLs generated by Next.js API Routes (Server Actions).

## Agent Instructions
- **Strictly use `bun`** for package management. Do not use `npm`, `yarn`, or `pnpm`.
- Ensure new components adhere to the existing Shadcn UI and Tailwind v4 setup.
- Always implement APIs securely, never exposing direct R2/AWS credentials to the client.
